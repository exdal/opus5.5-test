# OxCity — a GTA 2 style game built on Oxylus

A top-down 3D game (steal cars, drive, rob people and banks, get chased by police) written as a
field test of the [Oxylus engine](https://github.com/oxylusengine/Oxylus).

- `engine/` — Oxylus, vendored with `git subtree` so it can be patched locally.
- `game/` — the game.
- `docs/DEVLOG.md` — the journal of using the engine.
- `docs/ENGINE_CHANGES.md` — every change made to `engine/` and why.
- `docs/ENGINE_FEEDBACK.md` — bugs, friction and feature requests for the engine.
